# CREPO Course Library

A website where students of Computer and Robotics Education, UNN, create an account (with their department), then read and download course materials.

## Run it
1. Install Node.js (v18+) from https://nodejs.org
2. Open a terminal in this folder and run:

       npm install
       npm start

3. Open http://localhost:3000

## Admin
Sign up with the email `admin@crepo.local` (or set your own before starting):

    Windows (PowerShell):  $env:ADMIN_EMAIL="you@example.com"; npm start
    Mac/Linux:             ADMIN_EMAIL=you@example.com npm start

The admin sees an "Add course material" box to upload or delete files.
